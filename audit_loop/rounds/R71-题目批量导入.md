## [F-20260808-088] bulk_import_questions correct_answer 无 A-D 校验 + option 可空（F-071 create_question 同类漏改） — P3

- **级别**: P3（观察项；管理端输入校验缺失；F-071 同类漏改——模式 1）
- **维度**: 4 API 契约（输入校验面；模式 1 同类漏改）

- **事实**:
  - `BulkImportQuestionItem.correct_answer: str = "A"`（admin_schemas.py:858）——**默认 "A" 且无 A-D 枚举校验**（可传 "X"）
  - `option_a: str = ""` / `option_b: str = ""`（L854-855）——**默认空串可空**——可导入 option_a 空但 correct_answer="A" 的题
  - bulk_import_questions（book_service.py:180-191）：`correct_answer=item.correct_answer` 直接建 QuestionBank——**无 A-D/option 校验**
  - **与 F-071（R23 create_question）完全同类**：CreateQuestionRequest.correct_answer 也只限 1 字符不校验 A-D——两处题目写入均缺校验（模式 1 同类漏改，F-071 只报 create_question 未含 bulk）
  - 影响链：submit_answers 判分 `correct_answer == selected`（畸形题永远错/option 缺失无法作答）——R23 F-071 已证影响
- **证据**: ① admin_schemas.py:858 correct_answer 无枚举校验 + L854-855 option 可空；② book_service.py:180-191 直接入库；③ 排重确认：R23 F-071 文件仅为 advancement/schemas.py CreateQuestionRequest，未含 BulkImportQuestionItem——本项为同类漏改第 2 处
- **触发**: 运营批量导入题目 CSV（correct_answer 误填 "X" 或 option_a 留空）→ 畸形题入库 → 测验判分异常
- **影响**: 批量导入畸形题（判分异常/选项缺失）——比 create_question 影响面大（一次导入多题）；无资金/安全。管理端输入，P3 观察
- **建议**: ① BulkImportQuestionItem.correct_answer 改 `Literal["A","B","C","D"]`；② option_a/option_b 改必填非空（Field(min_length=1)）；③ 与 F-071 一并修复（两处题目写入统一校验）
- **排重**: 已 grep 确认不在 F-001~087 / C-001~163 中；F-071（create_question）为同类先例——本项为模式 1 漏改枚举（第 2 处题目写入）

## [F-20260808-106] upload_id 未校验直拼路径——路径遍历 + 分片参数无上限（P3）

- **级别**: P3（低-中：纵深防御缺陷；触发依赖 upload.manage 权限被攻破/泄漏，属第二层防护缺失）
- **位置**: backend/domain/admin/services/upload_service.py:142/172/221（session_dir = CHUNK_DIR / upload_id）；
  backend/domain/admin/routers/admin_books_router.py:335-390（router 无 upload_id 格式校验）
- **类别**: 路径遍历（输入校验缺失）+ 资源边界缺失
- **事实**: upload_id 直接拼接文件系统路径 `CHUNK_DIR / upload_id`（L142 save_chunk / L172 complete_upload /
  L221 get_upload_status），router `upload_id: str = Query(...)`（L336/L362/L381）**无格式校验**（无 pattern/
  min_length/字符白名单）
- **证据**:
  - admin_books_router.py:335-346 upload_id 裸 Query，无 pattern 校验（对照 chunk_index 有 ge=0、total_chunks 有
    ge=1——唯独 upload_id 无约束）
  - upload_service.py:142 `session_dir = CHUNK_DIR / upload_id` → 传入 `../../tmp/x` 时 session_dir 逃逸 CHUNK_DIR
  - 影响链：save_chunk 在逃逸目录写 chunk_000000（任意文件写，内容可控）+ meta.json；get_upload_status 读任意
    目录 meta.json 存在性/内容（文件存在性探测）
  - **分片参数边界**：chunk_index 仅 ge=0 无上限（可写任意序号文件）、total_chunks 仅 ge=1 无上限（complete 时
    range(total_chunks) 大循环读盘——DoS 面）
- **触发**: 攻击者获得 upload.manage 权限（管理端账号攻破/内部低权限角色越权）→ 传 `upload_id=../../..`
  任意写文件
- **影响**: ① 任意文件写（chunk 内容可控）→ 服务器文件破坏/部署面；② 任意路径探测；③ 大分片参数 DoS。
  权限前置（管理端专用），P3 纵深缺陷
- **建议**: ① router 加 `upload_id: str = Query(..., pattern=r"^[a-zA-Z0-9_-]{8,64}$")`（服务端生成 uuid 格式）；
  ② service 侧二次防御：`session_dir.resolve()` 后校验前缀在 CHUNK_DIR.resolve() 内；③ chunk_index/total_chunks
  加上限（如 le=10000）；④ save_chunk 加单分片大小限制（对齐 save_upload 10MB）
- **排重**: grep 无"upload_id 路径遍历/上传路径"历史；R24（生词域 audio_url）、F-024（audio_url 文件面）为
  URL 消费面，本条为上传写盘面，不同

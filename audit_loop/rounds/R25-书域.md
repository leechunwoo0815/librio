## [F-20260808-073] BookCreate 缺 age_min<=age_max 交叉校验 + isbn 格式校验缺失 — P3

- **级别**: P3（观察项；管理端输入校验缺失，数据质量；与 R20 F-069 / R23 F-071 同类模式）
- **维度**: 4 API 契约（输入校验面）
- **文件**: `backend/domain/book/schemas.py:12-32`（BookCreate）/ `backend/domain/book/service.py:157-188`（create_book）
- **事实**:
  - `age_min: int = Field(..., ge=3, le=15)`（schemas.py:21）+ `age_max: int = Field(..., ge=3, le=15)`（L22）——各自有界，但**无 age_min <= age_max 交叉校验**——可创建 age_min=15, age_max=3 的倒挂书
  - `isbn: str = Field(..., min_length=10, max_length=20)`（L15）——只限长度，**无 ISBN-10/13 格式校验**（可传 "1234567890" 等任意 10 字符）
  - `create_book`（service.py:157-188）直接入库（get_by_isbn 查重后）——无交叉/格式校验
- **证据**: ① schemas.py:21-22（无交叉校验）+ L15（无格式校验）；② service.py:157-188 create 直接入库；③ 排重 grep：findings 无"age 倒挂/ISBN 格式"命中；F-024（audio_url 文件面）不涉；F-026（搜索无 limit）不同面
- **触发**: 运营在管理后台创建图书，输入 age_min=15/age_max=3 或非 ISBN 格式的 isbn → 入库 → 前端展示年龄范围错乱（最小 15 岁/最大 3 岁）、ISBN 无法被标准 ISBN 工具识别
- **影响**: 图书数据质量（年龄范围倒挂影响推荐/筛选语义；ISBN 格式不规范影响外部对接/查询）。无资金/安全。管理端低频 + 运营输入规范则不影响
- **建议**: ① BookCreate/BookUpdate 加 model_validator 校验 `age_min <= age_max`（Pydantic 交叉校验）；② isbn 加格式校验（ISBN-10/13 校验和或正则）——至少校验 `^\d{9}[\dX]$|^\d{13}$`
- **排重**: 已 grep 确认不在 F-001~072 / C-001~117 中；R20 F-069（时段校验）/R23 F-071（correct_answer 校验）为同类"schema 校验缺失"模式

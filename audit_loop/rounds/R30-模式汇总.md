## [F-20260808-076] save_book_page_admin 先查后插无唯一约束——并发保存同页双 BookPage 记录 — P3

- **级别**: P3（观察项；管理端低频 + 并发窗口极小；模式 ① 第 3 处）
- **维度**: R4 并发补面（模式 ① 先查后插无唯一约束，F-066/F-075 同类）
- **文件**: `backend/domain/book/service.py:303-313`（save_book_page_admin）/ `backend/domain/reading/models.py:22-40`（BookPage 无唯一约束）
- **事实**:
  - save_book_page_admin（book/service.py:303-313）：`query(BookPage).filter(book_id, page_number).first()` 查重 → 无则 `db.add(page)`——**先查后插无 DB 唯一约束兜底**
  - `BookPage`（reading/models.py:22-40）`__table_args__` 空，book_id 仅 index=True，**无 (book_id, page_number) UniqueConstraint**
  - 并发保存同一本书同一页（双管理端/重试）→ 双事务都查无 → 都 add → 双 BookPage 记录
  - 读取端 get_book_page 取 first（无 order_by 确定性）→ 内容可能取自任一条
- **证据**: ① book/service.py:303-313 先查后插代码；② reading/models.py:29 __table_args__ 空 + 无 UniqueConstraint；③ 排重 grep：findings 无 BookPage 唯一约束命中；F-066（pay_fines）/F-075（enroll）为模式 ① 前两处，本项为第三处（模式 1 枚举）
- **触发**: 运营管理后台并发保存同一本书同一页内容（双端编辑/重试）→ MySQL 下双记录
- **影响**: 书籍页面内容重复（同页两条记录，读取顺序不定）；无资金/安全。管理端低频 + 并发窗口极小
- **建议**: ① BookPage 加 `UniqueConstraint("book_id", "page_number", name="uq_book_page")`（DB 兜底）；② 或 save_book_page_admin 用 upsert（SQLite 兼容：先查后插 + IntegrityError 兜底，参照 dictionary create_word L111-119 模式）
- **排重**: 已 grep 确认不在 F-001~075 / C-001~122 中；F-066/F-075 为模式 ① 前两处（pay_fines/enroll），本项为第三处

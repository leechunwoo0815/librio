## [F-20260808-113] AssessmentCreateRequest 缺字段校验——score 越界/status 自由串/teacher 悬空（P3）

- **级别**: P3（弱观察；管理端数据质量，无资金/安全；触发依赖运营不规范录入）
- **位置**: backend/domain/assessment/schemas.py:30-42（AssessmentCreateRequest）；backend/domain/assessment/
  service.py:221-249（create_assessment）
- **类别**: 管理端 schema 校验缺失（模式② 家族；F-069/F-071/F-073/F-074 同类——评估域漏改）
- **事实**: create_assessment 直接落库（L239-247）——**无以下校验**：
  - comprehension_score 无范围（可传 -1/999，应 0-100）
  - status 无枚举（自由字符串，应 pending/completed/cancelled 等）
  - teacher_id 无存在性校验（可传不存在老师 ID）
  - ar_level_before/after 无交叉校验（after < before 倒挂）
- **证据**:
  - schemas.py:30-42：comprehension_score/status/teacher_id 均无 Field 约束（对照 BookCreate 有 ge/le）
  - service.py:221-249：仅 child 存在校验（L225-231），teacher 无
  - **同类对照**：F-069（parent_course_time 时段无校验）/F-073（BookCreate age 倒挂）/F-071/F-074——
    管理端 schema 校验缺失家族，评估域为又一漏改点（防复发红线 1）
- **触发**: 管理端录入评估：score 传 999 / status 传任意串 / teacher_id 传不存在值
- **影响**: ① 评估数据质量差（score 越界影响统计聚合）；② status 自由串致前端状态展示错乱/过滤失效；
  ③ teacher 悬空记录无追溯。管理端低频 + 运营规范输入则弱。P3
- **建议**: ① comprehension_score: float = Field(None, ge=0, le=100)；② status 用 Literal 枚举；③
  teacher_id 存在性校验（service 层）；④ ar_level_after ≥ ar_level_before 交叉校验；修复时与 F-069/F-073
  同类模式统一处理（模式② 家族）
- **排重**: R19 C-112（CRUD 权限/软删面）未覆盖字段校验；F-068（ar_level 断链）为接线面不同；grep 无
  "assessment 字段校验"历史；F-069/F-071/F-073/F-074 为同类先例（不同实体）

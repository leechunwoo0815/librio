### [F-20260807-059] 维度 R9 reading 打卡链 — end_session 重复调用时长膨胀（end_time 已存在无守卫） — P3
- 位置: `backend/domain/reading/service.py` end_session（L304-340）
- 事实: end_session 对同一 session 可重复调用——`session.end_time = datetime.now()`（L317）每次覆盖刷新，`duration_seconds = int((end_time - start_time).total_seconds())`（L318-320）随 end_time 后移而单调增大；且每次调用都发布 `ReadingSessionCompletedEvent(duration_minutes=...)`（L331-337）→ `handle_session_completed_for_child_stats`（reading_handlers.py:19-24）→ `update_reading_stats`（child/service.py:414-436，with_for_update 行锁串行但**无幂等守卫**）→ total_reading_minutes 每次重复 end 再加一份。无 `end_time is not None` / status 已结束守卫，客户端可循环调用 end_session 无限刷阅读时长。
- 影响: 阅读时长统计（total_reading_minutes）可被任意膨胀——排行榜/家长端/对账任务的累计统计失真。无资金/安全边界风险（统计展示面）。SQLite 行锁 no-op 不影响本项（重复调用是顺序执行，非并发）。网络重试/前端重复提交同样触发。
- 建议: end_session 加状态守卫——`if session.end_time is not None: 拒绝或幂等返回`（对齐 C-101 submit_answers 的 L224 状态守卫模式）；或发布事件前判定"本次为首次结算"。ReadingSessionCompletedEvent 的 handler 侧无法幂等（无 session_id 传递），守卫必须在 service 层。
- 排重: F-053（cancel_order 无锁读-改-写）/F-058（review_submission 无锁读-改-写）为**并发无锁**模式 ≠ 本项（有行锁但缺状态守卫的**顺序重复调用**）；C-101 的 submit 守卫是 IN_PROGRESS 判定，本项是其未覆盖的 end_session 面。

### [F-20260807-060] 维度 R9 reading 打卡链 — 试读页数限制可被单次 end_session 绕过（start 查历史累计 / end 无上限无复核） — P3
- 位置: `backend/domain/reading/service.py` start_session（L270-293）+ end_session（L317-323）；`backend/domain/reading/schemas.py` EndSessionRequest（L54-59）
- 事实: 试读限制（trial_pages，默认 20 页）只在 start_session 检查**历史累计**（L280-287 `func.sum(ReadingSession.pages_read)` 全表聚合，无锁）——`total_pages >= trial_pages` 则拒绝新会话。但 end_session 直接 `session.pages_read = data.pages_read`（L321）写入客户端传入值，**无上限校验、无试读状态复核**：`EndSessionRequest.pages_read: int = 0`（schemas.py:57）无 Field 约束。试读用户只需在累计 < 20 时 start 一个会话，end 时传 pages_read=99999 → 单次结算任意突破限制并污染累计统计。
- 影响: 试读付费墙（trial_pages）形同虚设——试读用户可录入任意阅读页数/时长；对账/统计展示数据可信度受损。无资金/安全边界（非越权、非支付）。前端正常传真实页数，但 API 层无约束。
- 建议: ① EndSessionRequest 加 Field 上限（如 `Field(ge=0, le=合理页数)`）；② end_session 对 TRIAL 用户复核试读限制（累计+本次 > trial_pages 则拒绝或截断），对齐 start_session L270-293 逻辑；③ 或将 start 的"读历史累计"改为 end 时"读+本次"判定。
- 排重: 全库 grep 无"试读/trial"命中（首次）；F-026（题库搜索无 limit）不涉；F-057（答案泄漏刷词数）为测验面，本项为阅读面页数/时长——机制不同（客户端直传 vs 服务端泄漏）。

## [F-20260808-064] 排行榜全表 ORDER BY Child.total_words_read 无索引（用户侧热路径，R2 8.2 覆盖盲区） — P3

- **级别**: P3（观察项；小馆规模可接受，数据积累后全表 filesort 退化）
- **维度**: 8.2 索引覆盖（第三轮换面：用户侧排序 vs 管理端差集）
- **文件**: `backend/domain/advancement/leaderboard_service.py:95-115`（get_leaderboard 累计榜）/ `backend/domain/child/models.py:57`（total_words_read 无 index）
- **事实**:
  - `get_leaderboard`（累计排行榜）：`db.query(Child).filter(is_deleted==0, total_words_read>0, 可选 level_id/age_range).order_by(Child.total_words_read.desc()).limit(limit).all()`——**全表 ORDER BY 无索引列 total_words_read**
  - `Child.total_words_read`（models.py:57）`Column(Integer, default=0)` 无 index=True；Child 表 61 处索引声明中 child 域仅 1 个 index（L38，非 total_words_read）
  - R2 8.2 复核（findings L879-885）仅核对**管理端列表端点**（users/books/orders/borrows/bookcopy/damage-reports/reports）order_by 列——**未覆盖用户端 leaderboard**；L884 结论"无新增 filesort/全表风险点"遗漏该点
  - 用户侧 /advancement/leaderboard 为热路径（排行榜展示，前端 API 已封装 leaderboard 调用）
- **证据**: ① leaderboard_service.py:108 代码（order_by(Child.total_words_read.desc())）；② child/models.py:57 无 index；③ 排重 grep：findings 无"排行榜/leaderboard/total_words_read desc/ORDER BY words"命中（F-057 提排行榜仅为刷分影响面，非排序索引）；④ R2 8.2 复核范围明确为管理端（L879-885），用户端 leaderboard 漏
- **触发**: 用户频繁查看累计排行榜（家长端/老师端）→ 每次全表 filesort 按 total_words_read 排序
- **影响**: Child 表规模小时（小馆百级孩子）全表排序毫秒级无感；数据积累至千级+孩子时每次排行榜请求全表 filesort（无索引列排序），响应退化。非资金/非安全。低选择性考量：total_words_read 为数值列（非低基数枚举），索引有理论收益但小表无感——P3 观察
- **建议**: ① Child.total_words_read 加 index（或组合索引 (is_deleted, total_words_read)——覆盖过滤+排序）；② 或排行榜限 level 过滤减少排序集；③ 数据规模达阈值后再评估。R2 8.2 复核范围扩展至用户端排序列
- **排重**: 已 grep 确认不在 F-001~063 / C-001~106 中；C-025（61 索引全量）与 C-068/069（管理端复核）覆盖管理端，leaderboard 为用户端盲区；F-026（题库搜索无 limit）不同面（无 LIMIT vs 无索引排序）

### [P2-001] F-001 / F-004：Book.total_stock 读-改-写无行锁（全库枚举）

- **文件**: `backend/domain/deposit/service.py`（mark_book_lost L454-521 附近 L509）、
  `backend/domain/admin/services/damage_admin_service.py`（L127/268/369/454）、
  `backend/domain/borrow/service.py`（还书/借书库存增减）、`backend/domain/book/service.py`（batch_generate L298-299）
- **根因**: `book.total_stock = max((book.total_stock or 0) - 1, 0)` 读-改-写无行锁——并发借还/报损可
  丢失更新（库存虚高/虚低）
- **修复方案**（每个写点同一模式）:
  ```python
  # 改前
  book = self.db.query(Book).filter(Book.id == book_id).first()
  book.total_stock = max((book.total_stock or 0) - 1, 0)
  # 改后
  book = (self.db.query(Book)
          .filter(Book.id == book_id)
          .with_for_update()          # ← 行锁，与调用方 commit 同事务
          .first())
  book.total_stock = max((book.total_stock or 0) - 1, 0)
  ```
- **枚举清单（全部改）**: ① deposit/service.py:509 ② damage_admin_service.py:127（新_total）
  ③ damage_admin_service.py:268（mark_book_found +1）④ damage_admin_service.py:369/454（replace +1）
  ⑤ book/service.py batch_generate_copies:298-299 ⑥ borrow/service.py 借/还库存增减点（grep `total_stock` 全查）
- **防回归测试**（`tests/` 对应域）:
  ```python
  # test_stock_concurrency.py
  def test_mark_book_lost_concurrent_safe(concurrent_db):
      """并发 2 次 mark_book_lost 同一书：total_stock 只减 1（不双减）"""
      # 用 scripts/verify_mysql_concurrency.py 模式（SQLite with_for_update 为 no-op）
  ```
- **注意**: `reconcile_stock`（scheduler.py:257）为纠正性全量重算，不需加锁（R139 已核），勿动。

### [P2-004] F-023：分片上传 upload_id 路径遍历（写文件）

  session_dir = (CHUNK_DIR / upload_id).resolve()

  # ③ 分片参数上限
  chunk_index: int = Query(..., ge=0, le=10000)
  total_chunks: int = Query(..., ge=1, le=10000)
  # ④ save_chunk 单分片大小限制（对齐 save_upload 10MB）

## 6. 提交与回归纪律

1. **一次一主题**：每个 fix 单独 commit（`fix(domain): ...`），测试随代码同 commit
2. **先测后改**：每个修复先写测试 → 确认 RED → 修复 → GREEN（测试输出留证）
3. **禁止**：`as any`/`@ts-ignore`（TS）、`type: ignore` 绕过、删测试、改断言糊弄
4. **门禁全绿**：pytest + behave + ruff 全量（0.3 命令），报告真实输出
5. **特别警示**：
   - SQLite 下 `with_for_update` 是 no-op——并发修复必须用 `scripts/verify_mysql_concurrency.py`
     （独立 MySQL 测试库）实证
   - 加唯一约束/改索引需迁移脚本 + 存量数据清理（0.4 自检）
   - 涉及金额的修复（批次 1/2）优先做，验收以 MySQL 并发实证为准

# 扫码枪对接规范（门店借阅硬件）

> 版本：V1.0（2026-07-26）｜ 适用：门店扫码枪供应商、实施人员、门店店员
> 系统侧实现：B1a 已交付（commit 307ddb1）

---

## 一、硬件原理与选型

扫码枪本质是**键盘模拟设备（HID）**：扫一次 = 快速输入一串字符 + 回车。
无需驱动、无需 SDK，USB/蓝牙均可。

| 项 | 要求 |
|---|---|
| 接口 | USB HID 键盘模式（禁用串口/虚拟 COM 模式） |
| 回车符 | 任意（\r / \n / \r\n 系统均兼容） |
| 扫码制式 | 一维码 Code128（图书条码）、QR 二维码（会员码，需二维枪） |
| 建议 | 采购**二维影像式**扫码枪（同时读一维条码和手机 QR 会员码） |

## 二、条码编码规则

### 图书副本条码（一维，Code128）
```
{ISBN}-{副本序号}
示例：978-0-06-112495-1-001   （ISBN 978-0-06-112495-1 的第 1 本副本）
```
- 标签：建议 50×30mm 铜版纸 + 覆膜，贴于封底内页
- 打印：任意条码标签机（如得力/精臣），选 Code128
- 新书入库：管理端图书管理 → 副本管理 → 批量生成条码（系统已支持）

### 会员码（QR，手机出示）
家长小程序 → 我的 → 个人名片 → 出示 QR 码。店员扫码后系统解析定位孩子。
（注：会员码解析接口在 B1a 本期沿用"搜索孩子"方式定位，QR 直扫解析为后续增强项，不影响借还流程）

## 三、门店 SOP（标准作业流程）

### 借书（2 秒/单）
1. 管理后台 → 借阅管理 → 搜索孩子姓名/手机号（或扫会员码）
2. 扫图书条码 → 系统自动借出（校验：会员状态/押金/上限/副本状态）
3. 异常提示：
   - `请先缴纳押金` → 引导家长小程序缴押金
   - `借阅上限 20 本，请先归还` → 提示先还书
   - `该书已被借出，预计归还日期：YYYY-MM-DD` → 告知归期
   - `该书正在维修中，暂时无法借阅` / `已报废` / `已损坏` / `已丢失` → 换一本

### 还书（1 秒/单）
- 直接扫图书条码 → 自动归还；逾期自动计算罚款并提示

### 预约取书（2 秒/单）
1. 管理后台 → 预约管理 → 顶部「扫码取书」框（页面打开已自动聚焦）
2. 扫图书条码 → 系统自动匹配该书最早的待取预约并完成取书
3. 异常提示：
   - `条码 X 不存在，请先扫描入库` → 该书未建档
   - `该书当前没有待取预约` → 出示预约记录核对
   - `该副本状态异常，请联系工作人员` → 换同书其他副本
4. **备用**：断网/扫码枪故障时，列表中点「确认取书」手动完成（不登记具体副本）

### 防误扫
- 同一输入 0.5 秒内重复回车自动忽略（防枪头抖动连扫）
- 同一本书同一孩子重复借阅系统拦截： `该书已借阅，请先归还`

## 四、断网/降级预案

| 场景 | 处置 |
|---|---|
| 门店断网 | 纸质登记本记录（孩子+条码+时间），网络恢复后补录 |
| 扫码枪故障 | 全部操作均保留手动入口（搜索孩子/输入条码/点按钮） |
| 条码磨损 | 图书管理 → 副本管理 → 重打条码 |

## 五、技术契约（供应商联调用）

| 操作 | 端点 | 入参 | 说明 |
|---|---|---|---|
| 扫码借书 | POST /borrow/scan | child_id, barcode | 条码不存在可自动建档（需 title/isbn 等） |
| 扫码还书 | POST /borrow/scan-return | barcode | |
| 扫码取书 | POST /admin/api/reservations/fulfill | barcode | 自动匹配最早待取预约；或 reservation_id 手动备用 |
| 条码建档 | 管理端副本管理页 | — | 批量生成 |

- 全部端点需管理员 Token（管理后台登录态），无独立设备密钥
- 响应：HTTP 200 成功；4xx + `detail` 中文提示（直接展示给店员）

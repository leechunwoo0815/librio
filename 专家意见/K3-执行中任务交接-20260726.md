## 五、纪律与陷阱（累计，最新在前）

- **pytest/behave 并非纯内存**：9 例 pytest + 40 个 behave error 依赖本机 MySQL——"全绿"结论限定开发机环境（FINAL-3.0 勘误，沙箱复测已交叉验证）
- **BDD feature 硬编码种子数**：rbac.feature 教师权限数 29（加权限要同步改）；配置默认值同理（步骤默认值必须与服务端同步）
- **RBAC 种子无启动钩子**：新增权限码后必须手动对库重跑 seed_roles/seed_permissions/seed_role_permissions（幂等；get_session() 拿 SessionLocal）
- **给 User/Child 加列四同步**：迁移含存量回填 + Response schema 加字段 + 表结构.md 注记 + （若影响资格/计时）PRD 注记
- SQLite 测试老化时间：create_time 构造传参；update_time 有 onupdate 必须 text SQL 绕过；exited_at 无 onupdate 可构造传参
- ConfigService.set_config 需要 config_audit_log 表：测试文件 import backend.common.config_audit_model
- voice_recording.text_content/duration_seconds NOT NULL，测试造数必填；User.phone 唯一约束（用 hash 生成）
- 管理端新页面四件套：html + js/pages + css/pages + admin_page_router（PAGE_PERM_MAP+路由）+ base.html 侧边栏 data-perm；data-action 须被 wiring 7 种正则捕获；页面专属权限优于复用 dashboard.view
- 小程序 wxss 禁非注释 hex（一律 var(--xxx) token）；iOS 分支 wx:if/else 互斥时按钮放进 iOS 分支内
- 编辑文档 old_string 含下一节标题时 new_string 必须保留原标题
- pytest 全量约 4-6 分钟：后台任务 timeout 给 900s；behave 约 2 分钟
- alembic check 连开发 MySQL：新迁移先 upgrade head 再 check（"Target database is not up to date"≠漂移）
- with_for_update() 在 SQLite 为 no-op：单测只验功能
- 审查类反馈逐条给"属实/不成立/非bug/可接受风险"结论，不粉饰不硬顶；认账要快，勘误要全改
- 迁移改列后 alembic check 报注释漂移：迁移文件补 alter_column comment
- ConfigService._cache 进程级共享：测试间 set_config 后需 invalidate（fixture 尾部清理）
- behave 步骤名全局唯一；admin.username/role.code 唯一约束需 uuid 后缀
- timedelta.days 截断：剩余天数预期按截断后整数算
- check_model_consistency.py 被 import 会强制 DATABASE_URL=sqlite
- integration 需 MOCK_PAYMENT=true MOCK_SMS=true DEBUG=true；十一关命令在 CLAUDE.md §六
- 写审查令时先自查：18b 退款公式就是写审查令时自抓的（"按剩余天数÷45 结算"歧义照字面实现会少退 7 天费用）

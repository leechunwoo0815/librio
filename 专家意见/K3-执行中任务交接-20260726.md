## 三、关键新机制（后续开发必读）

- **时区铁律（批次15/16 定案）**：ORM 时间戳与业务比较一律应用侧 datetime.now()；禁用 func.now() 默认值与 UTC 混用（SQLite 存 UTC、MySQL 存会话时区，跨库必现偏差）。**JWT 例外**：jose 内部全程 UTC 时间戳，与业务时间无交叉，不算混用（批17 定案）
- **读完链路**：save_progress 读完→PENDING 提交+读完打卡（每类型每日1次）+total_books_finished 首读累计；测验通过+≥10min 自动 APPROVED（D4）
- **押金单号**：pay_order_id 为 String(64)（DP前缀），回调按字符串精确匹配
- **并发写入铁律（批17 定案）**：child 统计字段读改写必须 `with_for_update()`；"先查后插"必须 DB 唯一约束兜底 + `add_with_unique_fallback()`（SAVEPOINT 静默跳过）
- **金额/精度铁律（批17 补强）**：金额字段禁 float（schema 层也不许，Pydantic 会隐式转换）；与 Numeric 列比较的阈值一律 Decimal（float(0.80)*100=80.00000000000001 曾致边界误判）
- **搜索铁律（批17 定案）**：所有 LIKE/ILIKE 用户输入必须 `escape_like()` 转义 + `escape="\\"`（sql_utils.py）


- **fine_policy.py**：逾期服务费唯一计算口径（宽限 3 天/上限半价/首次免罚），任何地方算罚款必须走它
- **config_levels.py**：配置三级管控（locked 仅超管/warning 需 confirmed/free），新增配置键要登记级别
- **自动审核链**：refund ≤500、押金、活动退款自动批（权益转让仍人工）；audit_sla_escalation 每日巡检 4 队列
- **D4 提交流**：读完 PENDING → 测验通过+≥10 分钟自动 APPROVED（事件链晋级）
- **ALUMNI=5**：满 15 岁毕业态，不可借阅；EXITED 可 revive 为 TRIAL，历史订单计入多孩资格
- **iOS 支付**：门店收款码 pay-code + 对公转账 confirm-transfer（pay_type=2）
- **修改接口**：59 项配置全部可调（见 PRD/动态配置清单.md，由 DEFAULTS 脚本生成，改 DEFAULTS 后需重新生成该文档）

- **msg_sec_check v2**：errcode=0 不代表通过，必须查 `result.suggest`（risky/review 均拦截）+ detail 兜底

## 六、纪律与陷阱（累计，最新在前）

- alembic check 连的是开发 MySQL：新迁移必须先 `alembic upgrade head` 再 check，否则报 "Target database is not up to date"（这不是漂移）
- with_for_update() 在 SQLite 下为 no-op（方言不渲染不报错），单测只验功能；行锁语义仅 MySQL 生效
- 表结构.md 编辑注意：old_string 含下一节标题时 new_string 必须保留原标题（本次误吞 4.6 标题已当场修复）
- 时区类 bug 双向掩盖：改 func.now()→datetime.now() 后 SQLite 方向会反向暴露（integration 用 sqlite 文件库），必须双侧（MySQL+sqlite）都想一遍
- 测试 _execute_wechat_refund 这类自带 get_session() 的函数：monkeypatch 注入共享会话后要屏蔽函数尾部的 close()
- 审查类反馈逐条给"属实/不成立/非bug/可接受风险"结论，不粉饰不硬顶
- 迁移改列后 alembic check 会报注释漂移：迁移文件里补 alter_column comment；已应用的修订用 stamp + 手工 ALTER 补救
- 后台门禁任务会读到未提交的半批改动：每批先完整再跑门禁；background pytest 注意时效
- BDD 步骤硬编码配置默认值（如 vocab_lookup_limit", 10）会与服务端新默认脱节——步骤默认值必须与服务端同步
- ConfigService._cache 进程级共享：测试间 set_config 后需 invalidate（fixture 尾部清理）
- behave 步骤名全局唯一："系统返回403禁止"这类通用名不可重复定义
- admin.username / role.code 唯一约束：同场景多次建管理员需 uuid 后缀
- timedelta.days 截断：剩余天数预期值按截断后整数算（20 天→19）
- 集成脚本/BDD 的消息断言随文案变更（G 组）一起改，admin JS 的 includes 映射同步改
- check_model_consistency.py 被 import 会强制 DATABASE_URL=sqlite
- integration 需 MOCK_PAYMENT=true MOCK_SMS=true DEBUG=true；十关命令在 CLAUDE.md §六

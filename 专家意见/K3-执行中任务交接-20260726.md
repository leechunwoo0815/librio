## 四、关键机制定案（勿重开，除非有实测反证）

- **H5 计时基准**：退出计时一律 `child.exited_at`（update_status 唯一写入点/只写一次/revive 清空）；purge 豁免 user_id=0 管理端告警；consent_record 永不删
- **F5 快照**：`user.paid_member_ever` 兜底多孩资格（订单 purge 后资格仍有效）；4 个支付入口全覆盖（回调/管理员编辑/线下订单/update_order_status，A-1 已闭合）
- **决策（20260804，终审 P3-④ 闭环）**：管理端三个"标已付"入口置 PAID 仅写订单状态与 F5 快照，不发布 OrderPaidEvent、不自动激活会员；会员开通由管理员经 PUT /child/{id}/status（child.edit 权限）另行操作。理由：收款对账与会员开通职责分离；三入口行为一致且历轮审查无异议；上线冻结期不引入行为变更。再评估触发条件：甲方明确要求"管理端标已付即开通会员"时，作为独立变更批次处理——须三入口同补、增加"变更前状态非 PAID 才发事件"守卫、覆盖订单类型 × 孩子状态全矩阵回归测试。
- **iOS 支付分层**：实物担保（押金/补缴/罚款）放行 wx.requestPayment；虚拟服务（观察期/会员）iOS 隐藏价格+购买按钮，仅 platform.showIOSContactGuide（门店/客服）
- **并发写入铁律**：child 统计字段读改写必须 with_for_update()；"先查后插"必须 DB 唯一约束 + add_with_unique_fallback()（SAVEPOINT 兜底，sql_utils.py）
- **金额/精度铁律**：金额禁 float（含 schema 层）；与 Numeric 列比较的阈值一律 Decimal
- **搜索铁律**：LIKE/ILIKE 用户输入必须 escape_like() + escape="\\"
- **时区铁律**：ORM 时间戳与业务比较一律应用侧 datetime.now()；JWT 例外（jose 内部 UTC 时间戳，无交叉）
- **配置治理**：65 项动态配置改 DEFAULTS 后必须跑 `PYTHONPATH=. venv/bin/python scripts/gen_config_doc.py`（--check 已入 CI+Gate 11）；新数值键登记 CONFIG_RANGES（范围）+ config_levels（管控级别）；ConfigService.set_config 统一范围校验（422）
- **fine_policy.py**：逾期服务费唯一计算口径（宽限 3 天/上限半价/首次免罚）
- **自动审核链**：refund ≤500、押金、活动退款自动批（权益转让仍人工）；audit_sla_escalation 读 review_sla_hours（默认 24，超时告警阈值≠完成承诺）
- **读完链路**：save_progress 读完→PENDING 提交+读完打卡+total_books_finished；测验通过+≥10min 自动 APPROVED（D4）
- **今日全勤**：4 类型集满 → maybe_send_full_attendance_message（按日幂等）
- **ALUMNI=5 毕业 / EXITED 可 revive（历史订单计入多孩资格）/ 押金单号 String(64) / iOS pay-code+confirm-transfer / Redis 降级 REDIS_LOCK_FAIL_OPEN / access_token Redis 共享缓存 / msg_sec_check 查 result.suggest**

## 五、纪律与陷阱（累计，最新在前）

- **pytest/behave 并非纯内存**：9 例 pytest + 40 个 behave error 依赖本机 MySQL——"全绿"结论限定开发机环境（FINAL-3.0 勘误，沙箱复测已交叉验证）
- **BDD feature 硬编码种子数**：rbac.feature 教师权限数 29（加权限要同步改）；配置默认值同理（步骤默认值必须与服务端同步）
- **RBAC 种子无启动钩子**：新增权限码后必须手动对库重跑 seed_roles/seed_permissions/seed_role_permissions（幂等；get_session() 拿 SessionLocal）
- **给 User/Child 加列四同步**：迁移含存量回填 + Response schema 加字段 + 表结构.md 注记 + （若影响资格/计时）PRD 注记
- SQLite 测试老化时间：create_time 构造传参；update_time 有 onupdate 必须 text SQL 绕过；exited_at 无 onupdate 可构造传参
- ConfigService.set_config 需要 config_audit_log 表：测试文件 import backend.common.config_audit_model
- voice_recording.text_content/duration_seconds NOT NULL，测试造数必填；User.phone 唯一约束（用 hash 生成）
- 管理端新页面四件套：html + js/pages + css/pages + admin_page_router（PAGE_PERM_MAP+路由）+ base.html 侧边栏 data-perm；data-action 须被 wiring 7 种正则捕获；页面专属权限优于复用 dashboard.view
- 小程序 wxss 禁非注释 hex（一律 var(--xxx) token）；iOS 分支 wx:if/else 互斥时按钮放进 iOS 分支内
- 编辑文档 old_string 含下一节标题时 new_string 必须保留原标题
- pytest 全量约 4-6 分钟：后台任务 timeout 给 900s；behave 约 2 分钟
- alembic check 连开发 MySQL：新迁移先 upgrade head 再 check（"Target database is not up to date"≠漂移）
- with_for_update() 在 SQLite 为 no-op：单测只验功能
- 审查类反馈逐条给"属实/不成立/非bug/可接受风险"结论，不粉饰不硬顶；认账要快，勘误要全改
- 迁移改列后 alembic check 报注释漂移：迁移文件补 alter_column comment
- ConfigService._cache 进程级共享：测试间 set_config 后需 invalidate（fixture 尾部清理）
- behave 步骤名全局唯一；admin.username/role.code 唯一约束需 uuid 后缀
- timedelta.days 截断：剩余天数预期按截断后整数算
- check_model_consistency.py 被 import 会强制 DATABASE_URL=sqlite
- integration 需 MOCK_PAYMENT=true MOCK_SMS=true DEBUG=true；十一关命令在 CLAUDE.md §六
- 写审查令时先自查：18b 退款公式就是写审查令时自抓的（"按剩余天数÷45 结算"歧义照字面实现会少退 7 天费用）

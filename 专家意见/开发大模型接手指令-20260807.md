## 四、强制性约束（违反任何一条 = 返工重写）

### 4.1 防幻觉（最高优先）
- 改任何代码前，先用工具读取相关文件；禁止凭记忆/脑内默写
- 找不到依据直接说"无相关记录"，禁止编造
- 报告里的数字必须来自命令输出，禁止估算/快照/事后回忆

### 4.2 修复纪律
- 修"一类 bug"：先 `rg` 全库枚举同类调用点/入口，逐个核对，兄弟路径各补测试
  （历史 6+ 次栽在同类漏改：支付入口/退款调用/状态变更点）
- 数值/日期/金额：写边界矩阵 [-1, 0, +1]（当天/跨月/闰年/阈值+最小单位）
- 新字段/单号/回调/迁移：回答契约三维——会被第二处流程复用吗？异步回调/重试能区分
  各笔业务吗？存量数据需要回填吗？
- 状态机：先画允许转移矩阵对照 PRD，禁止非法转移/死状态
- 最小改动：不做未要求的重构/改名/格式化；发现无关问题报告但不顺手修

### 4.3 测试纪律（假绿是项目最大教训）
- 测试走真实 service/API 路径；禁止 ORM 伪造、自带业务公式、恒真断言、空断言
- 关键修复做 RED→GREEN：临时撤修复行，测试必须转红
- 契约测试用差异场景：部分退款（total≠refund）、网关拒绝、非 SUCCESS 回调
- MySQL-only 检查必须真跑：alembic upgrade head + check、`scripts/verify_mysql_concurrency.py`、
  时区边界——禁止标"没法跑"跳过

### 4.4 门禁纪律（声称完成前）
- 门禁命令**全量复制** CLAUDE.md §八原文，禁止缩窄目录/靶标（尤其 ruff format 全仓 `.`）
- 交付报告必须贴五项原始输出：ruff / pytest / behave / integration / alembic check
  + 自检闭环验证表（对照本 § 逐项打勾）
- 改基线数字（pytest 数/API 数/表数等）后，全库 `rg` 同口径核对所有文档

### 4.5 配置/迁移纪律
- 加列四同步：迁移回填 + 模型 + 表结构.md + PRD；配置四同步：DEFAULTS + RANGES +
  SECTIONS + 动态配置清单（`gen_config_doc --check` 必须过）
- 新迁移前 `alembic history` 确认编号不重复；引用迁移号以实际文件为准
- 新增迁移交付前，开发机跑 `alembic upgrade head` + `alembic check`

### 4.6 环境陷阱（速查）
- pytest 通过数随环境，报告注明口径；SQLite 行锁 no-op（并发用 MySQL 脚本）
- `timedelta.days` 截断；金额禁 float（用 Decimal）；用户输入 LIKE 必须 escape_like
- 时区用应用侧 `datetime.now`（JWT 例外）
- 管理端新页面四件套（html/js/css/路由 + data-action 须被 wiring 正则捕获）
- 小程序 wxss 禁非注释 hex；BDD feature 硬编码种子数注意同步
- 只用 `venv/bin/...`，不要用 .venv/ 或系统 python

### 4.7 git 纪律
- Conventional commits：feat/fix/chore/refactor/test/docs；正文中文
- 提交前 `git diff` 检查，只 stage 预期文件；不 commit 未完成代码/调试日志/注释块
- 禁止 `git push --force` / `git reset --hard` / `rm -rf`；破坏性操作先说明影响
- 每完成一个可独立验证的批次即提交推送，工作区保持干净

## 六、工作方式与输出规范

- 中文回复，代码/标识符/commit 信息用英文
- 直接给结论，不奉承；不确定就明说不确定，不猜
- 输出只给 diff/摘要与行号，不整文件粘贴
- 每个任务交付格式：
  1. 改动清单（文件 + 行号 + 一句话）
  2. 测试/门禁原始输出（五项 + 相关单测）
  3. 自检闭环验证表（对照 §四 逐项打勾）
  4. commit hash（含推送确认）
- 遇到三种情况立即停下汇报，不硬闯：
  a. 缺甲方/产品口径（见 §五 待拍板清单）
  b. 需求模糊或两种以上合理实现
  c. 门禁失败无法定位（连续 2 次同一报错触发断路器，输出 Traceback 请求人工介入）
- 上下文管理：长文档分段读不重复读；每完成一个批次 git commit + 汇报，防工作丢失
- 每轮大审查/大修复后：按 error_list/README.md 六步重做错误记忆库

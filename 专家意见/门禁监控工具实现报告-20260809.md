## 二、规格对照（四功能全实现）

### 功能 1：实时监控（替代 sleep 死等）

- 增量读取：打开文件后 `seek(0, SEEK_END)`，每轮只消费新追加的**完整行**，不重扫全文（规格 §二.1）
- 半行缓冲：二进制读取，遇末尾无换行的半行即回退偏移，留到下一轮与新内容拼接后再处理（写端块缓冲 flush 断行防护，专家审查 P2-1，见 §十）
- 完成标记：`--done-marker` 默认 `===== GATES DONE =====`，命中即打印汇总并自动退出（规格 §二.1）；半行 DONE 拼接后同样识别
- 超时保护：`--timeout` 默认 900s，超时打印错误 + 当前统计，退出码 3
- 文件轮转/重建：每轮 `os.stat` 对比 inode（mv 重建）**且对比 size < 已读偏移**（同 inode 截断，规格 §三 逐字"inode 或大小变化时重新打开"，专家审查 P2-2，见 §十）
- 启动回扫：`--tail-lines N` 把文件末尾 N 行纳入首轮统计（0=不回扫，默认）；回扫同样走半行缓冲

### 功能 2：错误检测

- 判定规则（规格 §二.2 + v2 补强，任一命中即失败）：
  - `N failed` 且 `N > 0`（含 pytest 结果行 `N passed, M failed` 的 M>0 场景）
  - `failed`/`FAIL` 文本（大小写不敏感；`0 failed` 与 `PASSED`/`passed` 行除外）
  - `ERROR`、`Traceback` 任意出现
  - **v2 补强（规格 §二.2 增补，依据见 §十 P2-3）**：`N error(s)` 且 `N > 0`（pytest collection error 小写汇总行）、`Interrupted` 关键字——防纯 collection error 门禁假绿退出 0
- **设计决策（规格 §三 匹配逻辑的歧义裁决）**：错误检测独立于结果行匹配执行——`ERROR`/`Traceback` 不在默认 pattern（原命令 grep 原文）中，若仅在结果行上叠加判定则这两条规则永远不生效（死代码）。裁决依据：§二.2 的功能目标为"实时识别失败行并醒目输出"，失败信号不依赖 pattern 命中；结果行匹配仅决定计数与普通输出
- 输出：失败行 `[FAIL]` 前缀 + ANSI 红色（仅 tty 输出 ANSI，非 tty 自动省略，规格 §二.2）
- `--exit-on-error`：发现失败行立即退出码 1（fail-fast），**启动时回扫文件已有全部内容**——否则预写失败行永远不可见（见 §四 缺陷 3）

### 功能 3：结果计数

- 计数口径（规格 §二.3）：
  | 计数 | 来源 |
  |---|---|
  | `passed` | `N passed` 数字累加（多行累加；兼容 `211 scenarios passed` 名词间隔格式） |
  | `failed` | `N failed` 数字累加 |
  | `PASS` | `[PASS]` 前缀行数（MySQL 并发场景） |
  | `FAIL` | `[FAIL]` 前缀行数 |
  | `OK` | `OK:` 开头行数 |
  | `No-new` | 含 `No new` 行数（alembic 无迁移行） |
- 实时周期统计：`[stats] period=+N total=M matched=K passed=X failed=Y`，`--stats-every` 默认 60s（0=仅退出时）；**v2：period=+N 为统计窗口内累计增量**（P3-3 修正，不再只是最近单轮）
- 退出汇总：
  ```
  [summary] passed=2510 failed=0 PASS=9 FAIL=0 OK=3 No-new=1
  [summary] 段: PYTEST✓ BEHAVE✓ RUFF✓ CONTRACT✓ MODEL✓ WIRING✓ CONFIG✓ INTEGRATION✓ ALEMBIC✓ MYSQL✓
  ```
- 段名收集：`===== 段名 =====` 行按出现顺序记录（**v2：恰 5 等号 + 规格 §一 白名单校验**，pytest 6 等号横幅/`short test summary info` 等垃圾段不再入清单，P2-3，见 §十），汇总时逐个 `✓`（排除 GATES DONE）

## 四、TDD 抓出的 4 个缺陷（已修复，均先 RED 后 GREEN）

1. **正则不匹配 behave 行**：`(\d+)\s+passed` 匹配不到 `211 scenarios passed`（数字与动词间有名词）。修复：`(\d+)\s+(?:\w+\s+)*passed`（failed 同理）
2. **回扫中 DONE 不退出**：`--tail-lines` 回扫命中 DONE 只 break 进主循环继续轮询 → 历史文件必然超时误报码 3。修复：回扫与主循环共用 `scan_lines()`，DONE 命中即汇总退出
3. **exit-on-error 对预写失败行失效**：启动 `seek(END)` 跳过已有内容，验收场景 2（预写 `2 failed` 行）永远读不到。修复：`--exit-on-error` 启动时回扫文件已有全部内容
4. **错误检测死代码**：`ERROR`/`Traceback` 不在默认 pattern 内，按"结果行上叠加判定"则永不生效。修复：错误检测对每行独立执行，结果行匹配仅决定计数与普通输出（裁决见 §二 功能 2）

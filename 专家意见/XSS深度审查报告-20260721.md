## 二、P0：Jinja2 `Template()` 默认 autoescape=False（实测确认）

**位置**：
- `backend/domain/report/service.py:321`（观察期报告 HTML）
- `backend/domain/certificate/service.py:131`（晋级证书 HTML）

**实测证据**：
```python
Template('<div>{{ name }}</div>').render(name='<img src=x onerror=alert(1)>')
# 输出: <div><img src=x onerror=alert(1)></div>  ← payload 原样输出
```

**攻击场景**：
- 家长给孩子起名带 XSS payload（C 端可写）→ 渲染进观察期报告/证书 → 管理员或家长打开 HTML 页面即执行
- 老师评语（管理端录入）带 payload → 家长打开观察期报告执行

**影响**：`/report/observation/{child_id}/html` 和证书 HTML 端点均为登录可访问页面，token 存 localStorage，XSS 可直接窃取。

**修法（必做）**：
```python
from jinja2 import Environment, select_autoescape
env = Environment(autoescape=select_autoescape(default=True, default_for_string=True))
template = env.from_string(f.read())
```
两处都改。注意：模板中 `{{ teacher_comment_section }}` 是 service 层拼装的 HTML 片段（含 `<div>` 标签），开启 autoescape 后会被转义显示为文本——需要把该片段改为模板内 `| safe` 显式标记（仅此一处），其余变量全部自动转义。

## 四、🟠 最高危：onclick 属性拼接 + C 端可控（4 点，实际危险度等同 🔴）

**模式**：`onclick="fn(' + jsEscape(用户输入) + ')"`，`jsEscape`（base-init.js:85）只转义 `\` 和 `'`，**不转 `"`**。onclick 属性是双引号包裹，payload `x"><img src=x onerror=alert(1)>` 闭合属性后自动触发。

| # | 文件：行 | 变量 | 可控方 |
|---|---------|------|--------|
| 1 | users.js:123 | `jsEscape(u.parent_name)`, `jsEscape(u.phone)` | **家长端注册/编辑（无需权限）** ⚠️⚠️ |
| 2 | users.js:186 | `jsEscape(c.name)`, `jsEscape(c.english_name)`, `jsEscape(c.grade)` | **家长端填写孩子信息** ⚠️⚠️ |
| 3 | submissions.js:95 | `jsEscape(s.child_name)`, `jsEscape(s.book_title)` | 家长端 + 管理端图书 |
| 4 | certificates.js:66 | `escapeAttr(cert.child_name)`（`&#39;` 编码在属性解码后还原，JS 逃逸成立） | **家长端** ⚠️⚠️ |

另有 12 个同模式管理端可控点（teachers/venues/books/content/audio/dictionary/levels/roles/settings/recycle_bin/questions），危险度次之。

**修法（系统性，不止补点）**：
1. 升级 `jsEscape`：同时转义 `"` `&` `<` `>`（`"` → `&quot;`，`&` → `&amp;` 必须最先替换）
2. **更优解**：废弃 onclick 字符串拼接，改 `data-*` 属性 + 事件委托（addEventListener），一次改造永久免疫。建议先在 4 个 C 端可控点落地，其余 12 点排第二批
3. `escapeAttr`（certificates.js/audio.js）同样升级

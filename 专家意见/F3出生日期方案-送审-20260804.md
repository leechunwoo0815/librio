## 二、四件套详设

### 1. 迁移 046（F7 已占用 045：order.activation_issue；F3 迁移顺延为 046）

```python
with op.batch_alter_table("child") as batch_op:
    batch_op.add_column(sa.Column("birth_date", sa.Date(), nullable=True,
                                  comment="出生日期（F2 毕业周岁判定，选填；NULL 回退 age 口径）"))
    batch_op.add_column(sa.Column("birth_date_estimated", sa.SmallInteger(),
                                  nullable=False, server_default="0",
                                  comment="birth_date 来源: 0=家长填写 1=存量估算回填"))
# 存量回填（估算：当年 1 月 1 日 = 当前年份 − age；MySQL 语法）
op.execute("""
UPDATE child SET birth_date = DATE(CONCAT(YEAR(NOW()) - age, '-01-01')), birth_date_estimated = 1
WHERE birth_date IS NULL AND age IS NOT NULL
""")
```

- 估算偏差说明：年中入学者按当年 1 月 1 日估算会偏大 ≤11 个月（即"提前毕业"最坏提前不到 1 年）；
  标记 `birth_date_estimated=1` 供管理端/报表识别，后续家长补填可覆盖。
- downgrade：drop 两列。
- 测试库 SQLite 走 `Base.metadata.create_all`（不受迁移 SQL 影响）；迁移本身在开发 MySQL 上验证。

### 2. 任务改写（`graduate_children`，scheduler.py:1380-1410）

- 周岁判定（应用侧计算，跨库一致，规避 2/29 闰年坑）：
  ```python
  def _age_reached(birth_date, years, today=None):
      today = today or date.today()
      return (today.year - birth_date.year) > years or (
          (today.year - birth_date.year) == years
          and (today.month, today.day) >= (birth_date.month, birth_date.day)
      )
  ```
- 毕业过滤：`birth_date IS NOT NULL` 的孩子按周岁 ≥15；`birth_date IS NULL` 的孩子**回退现有 `age >= 15`**（D3 口径）。
